# Toza Shared Copy System — Revision Brief

Status: **Phase 1.5 mandatory workstream**  
Purpose: prevent approved shared components from reintroducing repetition after page-level compression.

## Scope

Review and approve the shared English copy that appears across or supports multiple pages:

1. navigation labels;
2. primary CTA label;
3. shared footer contact block;
4. neutral first-message guidance;
5. short trust line;
6. footer descriptor;
7. reusable privacy/approval wording;
8. reusable short service descriptions;
9. credit wording;
10. urgent wording;
11. structured-content descriptions;
12. LLMS/reference summary where it mirrors public facts.

## Governing rule

Shared copy is not exempt from editorial review merely because it is reused.

The shared system must:
- preserve factual consistency;
- minimize duplicate page-level explanation;
- keep contact/purchase boundaries clear;
- remain compact enough not to undo page compression;
- avoid absolute privacy claims;
- preserve neutral first-contact language;
- use current commercial authority.

## Component rules

### Primary CTA
Locked default:
**Request a private conversation**

### Shared contact block
Must communicate:
- WhatsApp/Signal contact;
- short, neutral first message;
- personal reply;
- qualification before paid work;
- no commitment merely by contacting;
- no sensitive material in the first message.

It should not repeat the full Assessment description, pricing, or service-boundary catalogue.

### Short trust line
Should carry only high-value trust facts, not a mini privacy policy.

Default direction:
**In person · With you present · You control your credentials**

### Reusable privacy wording
Use the full version only where needed.

Do not shorten into:
- no cloud;
- no logs;
- no third parties;
- invisible contact.

### Service descriptions
Must match current authority:
- Assessment ₪3,600 including VAT;
- current two-device scope;
- current duration language;
- Personal Shield ₪14,000 including VAT;
- Inner Circle from ₪42,000 including VAT;
- Bespoke individually scoped/priced;
- current credit rules.

### Structured/reference content
Must not introduce claims absent from visible approved copy.

## Phase 1.5 output

Produce:
1. exact approved shared contact module;
2. exact short trust line;
3. exact footer descriptor;
4. exact reusable privacy wording;
5. exact short service descriptions;
6. exact structured/reference descriptions;
7. duplication map showing which page-level blocks can now be removed because the shared system carries them.

## Gate

Do not begin Home revision until the Shared Copy System is approved or explicitly marked provisional.

Reason: Home and situation-page compression depends on knowing what the shared components will already communicate.
