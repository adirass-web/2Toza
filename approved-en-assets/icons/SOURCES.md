# Icon provenance

Current UI family: Tabler Icons 3.52.0, MIT licensed. Selected static source SVGs, license and per-icon manifest are in `tabler/`. These replace the earlier Simple Icons contact glyphs on shared contact controls. No browser icon runtime, webfont or CDN is used.

The existing `whatsapp.svg` and `signal.svg` and CC0 license record are retained as historical source assets; current templates reference Tabler. The wordmark and editorial illustrations are unchanged.
